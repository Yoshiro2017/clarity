About Clarity

This website was created with a straightforward philosophy: information should be presented clearly, it should be accessible to everyone, and it should remain free of commercial influence or hidden surveillance. Whether you are visiting on a desktop computer, a tablet, or a phone, the layout adapts to ensure that content remains readable and well-organized.

The design uses the Noto family of typefaces — a comprehensive set of fonts designed to support every written language in the world. Noto Sans and Noto Serif provide excellent readability for body text, while Noto Sans Display and Noto Serif Display offer refined letter spacing and proportions for headings and titles at larger sizes. Noto Sans Mono is used where fixed-width characters are appropriate, such as code snippets or technical examples. Additional language support includes Noto Sans Adlam, Noto Sans Adlam Unjoined, and Noto Serif Ahom.

You may switch between light and dark appearance using the icon in the navigation bar. Your preference will be remembered automatically. If you have not yet made a selection, the site will match your operating system's theme setting by default. Transitions between themes are smooth and designed to be easy on the eyes.

Design Philosophy

Every design decision here follows three principles: legibility first, consistency throughout, and minimal overhead. Content is separated from presentation, files are organized logically, and everything is structured so that it can be maintained, extended, or adapted by anyone. This approach is not just about aesthetics — it is about respect for your time, your attention, and your privacy.

Documentation

This section explains how Clarity is structured, how to modify it, and how to deploy it. It is written to be accessible to beginners while remaining thorough enough to be useful to more experienced developers.

File Structure

All files are organized in a flat directory structure for simplicity. There are no subfolders by default, though you may add them as your site grows. The main files are:

  • index.html — The main page containing all content and navigation structure.
  • style.css — All visual styling including fonts, colors, spacing, and responsive behavior.
  • script.js — Page navigation and theme preference handling.
  • LICENSE — Full text of the MIT License.
  • README.md — Overview, setup instructions, and deployment guide.
  • .gitignore — Files that should not be tracked by Git.

Adding Content

To edit existing pages, simply locate the corresponding <div id="page-name" class="page"> block in index.html and modify the text inside. Headings use <h2> for page titles and <h3> for subsections. Paragraphs are wrapped in <p> tags. This consistent hierarchy helps screen readers and search engines understand the structure of your content.

To add a completely new page, create a new block following the same pattern, give it a unique id, and add a corresponding navigation link in the <ul class="nav-links"> list. The navigation script will detect it automatically — no JavaScript changes are required.

Styling and Appearance

All design values are defined as CSS variables at the top of style.css. This makes it easy to adjust colors, fonts, spacing, or rounded corners across the entire site by changing only one place. For example, modifying the --color-accent variable will update buttons, links, and highlights everywhere they appear.

Font assignments follow a deliberate pattern — see the Font Commands page for details.

Deployment

To publish Clarity using GitHub Pages, create a repository named Yoshiro2017.github.io. Upload your files, then go to the repository Settings, navigate to Pages, and select the main branch as the source. Your site will be live within a few minutes. No server configuration or database setup is needed — everything runs directly in the visitor's browser.

You may also host these files on any other web server or service that supports static HTML. The code does not require any server-side language or special environment.

Font Commands

This page describes how to change, assign, and apply fonts throughout Clarity. All font selection is controlled through CSS variables defined in style.css, making modifications straightforward and consistent.

Available Font Families

The following Noto font families are loaded and ready for use:

  • Noto Sans Display — Optimized for headings and titles at larger sizes
  • Noto Serif Display — Serif variant for formal or editorial headings
  • Noto Sans — Primary sans-serif for body text and paragraphs
  • Noto Serif — Serif variant for articles, long-form text, or emphasis
  • Noto Sans Mono — Fixed-width for code, data, and technical notation
  • Noto Serif Ahom — Full Ahom script support
  • Noto Sans Adlam — Joined Adlam; traditional standard form
  • Noto Sans Adlam Unjoined — Separated form; designed for education and learners

Adlam Usage Notes

Noto Sans Adlam renders characters in their traditional connected form. This is the standard writing style used in publications, books, and general writing.

Noto Sans Adlam Unjoined keeps each letter separate. This form is specifically intended for educational materials, children's books, and language instruction where identifying individual characters is helpful.

Current Assignments

These are the default assignments in the :root section of style.css:

--font-display: 'Noto Sans Display', 'Noto Serif Display', system-ui, sans-serif;
--font-heading: 'Noto Sans', 'Noto Serif', system-ui, sans-serif;
--font-body: 'Noto Sans', 'Noto Serif', system-ui, sans-serif;
--font-mono: 'Noto Sans Mono', monospace;
--font-ahom: 'Noto Serif Ahom', serif;
--font-adlam-joined: 'Noto Sans Adlam', sans-serif;
--font-adlam-unjoined: 'Noto Sans Adlam Unjoined', sans-serif;

How to Change the Base Font

To change the font used across all paragraphs and body text, edit the --font-body variable:

--font-body: 'Noto Serif', system-ui, serif;

This will apply the change site-wide without needing to modify any other rules.

How to Change Heading Fonts

To change headings and subheadings, update --font-heading:

--font-heading: 'Noto Serif Display', serif;

Page titles use --font-display separately so they can have a distinct appearance from subheadings:

--font-display: 'Noto Serif Display', serif;

Applying Font to Specific Elements

To apply a font family directly to one element or section:

font-family: 'Noto Serif Ahom', serif;
font-family: 'Noto Sans Adlam', sans-serif;
font-family: 'Noto Sans Adlam Unjoined', sans-serif;
font-family: 'Noto Sans Mono', monospace;

Font Weights and Styles

The loaded range for each family supports variable weights and widths:

  • Display families: 100–900 weight, 62.5%–100% width, italic available
  • Sans / Serif: 100–900 weight, 62.5%–100% width, italic available
  • Mono: 100–900 weight, 62.5%–100% width
  • Ahom: 400–700 weight
  • Adlam (both): 400–700 weight

Example usage in CSS:

font-weight: 400;   /* Regular */
font-weight: 600;   /* Semi-bold */
font-weight: 700;   /* Bold */
font-style: italic;
font-stretch: 75%;

Removing or Replacing Font Sources

To remove a font from being loaded, delete its corresponding line in the <head> section of index.html. This reduces page load size but may remove fallback support. To replace with a different font, update the href in the font link and adjust the CSS variable names accordingly.

Frequently Asked Questions

What is Clarity?

Clarity is a clean, professional website template designed for clarity, accessibility, and privacy. It is free of advertisements and tracking scripts, fully open-source, and released under the MIT License.

Do I need coding experience to use this?

Not necessarily. Basic changes such as updating text, replacing contact information, or selecting a new accent color can be done by editing the files directly in any text editor. More advanced modifications — adding new layouts or changing styling — benefit from some familiarity with HTML and CSS, but the code is structured to be as readable and self-explanatory as possible.

Where can I host this site?

These files are pure static HTML, CSS, and JavaScript — no server-side language or database is required. You can host them on GitHub Pages, Netlify, Vercel, Tiiny.host, or any standard web hosting provider. For GitHub Pages, create a repository named after your username and upload the files to the main branch.

Why use the Noto font family?

Noto was selected for its comprehensive language support, open licensing under the SIL OFL, and consistent visual quality across styles and weights. It is designed and maintained by Google and contributors to be readable on every device and in every language. The separation of Display variants for headings and standard variants for body text provides typographic refinement at every size.

What is the difference between the two Adlam fonts?

Noto Sans Adlam shows the traditional connected letter forms used in standard writing and publications. Noto Sans Adlam Unjoined keeps letters separate and is intended for educational materials, textbooks, and language learning resources.

How do I change the accent color?

Open style.css and locate the :root section. Modify the value of --color-accent and --color-accent-hover to any valid hexadecimal or RGB color. The change will apply across the entire site automatically.

Does this site collect visitor data?

No. Clarity does not embed analytics scripts, tracking pixels, or fingerprinting mechanisms. When fonts are loaded from Google's servers, standard web requests are made — this is inherent to how the web functions and not an additional tracking feature. Theme preference is stored locally in the visitor's browser using localStorage and is never transmitted to any server.

Can I remove the font links and host fonts locally?

Yes. Downloading and serving the fonts alongside your other files is the recommended approach for maximum privacy and independence. Once you have the font files, update the CSS to use @font-face pointing to your local files and remove the corresponding <link> lines from index.html.

How do I add a new page?

Follow the pattern of existing pages: add a navigation link in the list, then create a new <div id="page-id" class="page"> block with your content. The navigation system detects new pages automatically — no changes to JavaScript are needed.

Where do I direct questions or suggestions?

See the Contact page. For technical matters or code improvements, opening an issue or pull request on GitHub is the preferred method.

Typography and Fonts

The Noto font family was selected for its comprehensive language support, open licensing, and consistent design quality across styles and weights. Developed by Google and contributors, every font in the family is released under the SIL Open Font License, which permits free use and redistribution without restrictions. The full set of available weights and widths gives you fine-grained control over emphasis and hierarchy.

For best results, match the font to its purpose: Display variants are optimized for larger sizes and tighter spacing, making them ideal for titles and headings. Standard variants are designed for paragraph text at normal reading distances. Monospace fonts are intended for code, data, or any content where character width must remain constant.

Web Standards and Accessibility

Building sites that work well for everyone means following established standards and designing with accessibility in mind from the beginning. Semantic HTML — using the correct element for its intended purpose — is the foundation of this approach. It ensures that assistive technologies can interpret content correctly, that search engines can index it accurately, and that your site remains functional even when styling is disabled.

Key guidelines include maintaining sufficient color contrast between text and background, providing descriptive link text rather than generic phrases, ensuring that all interactive elements are usable with a keyboard alone, and structuring headings in a logical order. These practices benefit all visitors, not those using specialized tools.

Privacy and Independence

You do not need to collect data to build a useful or successful website. Clarity does not use analytics scripts, fingerprint visitors, or embed third-party tracking pixels. When a site loads resources such as fonts from external sources, the standard web request may include basic information such as IP address and browser type — this is inherent to how the web works, not an additional choice made here.

If you are building your own site, consider what you include and why. Every third-party script adds potential privacy implications and performance costs. Defaulting to minimal, self-contained code is a responsible design decision that respects your visitors.

Recommended Reading

Further information on these topics can be found in publicly available documentation from the World Wide Web Consortium (W3C), the Web Content Accessibility Guidelines (WCAG), and the Mozilla Developer Network (MDN). These are authoritative, community-maintained resources that explain web standards clearly and without cost.

Design Observations

Consistency is more powerful than many people realize. When every element behaves predictably, visitors can focus on content rather than learning how to navigate your interface. Small details — the same hover effect on every link, the same width for every paragraph block, the same spacing above every heading — combine to create a feeling of reliability and care. It is not about being perfect; it is about being predictable.

White space is not empty space; it is an active part of the design. It guides the eye, separates ideas, and gives content room to breathe. Resist the urge to fill every gap. Generous spacing improves readability and gives the page a calm, uncluttered character.

Technical Notes

JavaScript should enhance a page, not be required for it. The navigation system here provides smooth transitions and theme memory, but Clarity remains fully functional even if scripting is disabled. This progressive enhancement approach ensures maximum compatibility and graceful degradation across every environment.

External resources are kept to a minimum. Only the font and icon sets are loaded from outside sources. Everything else — structure, styling, and behavior — is contained directly within these files. This reduces dependency on third-party services and makes the site easier to archive, mirror, or run offline.

Change is inevitable, but it should be deliberate. When updating or rebuilding, preserve the principles that make Clarity work: clarity, restraint, and respect for the visitor.
